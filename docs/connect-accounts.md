# 连接账号：只在需要时做

安装技能不会自动登录你的账号。先试一个文件任务，再连接你真正要用的服务。

## 邮箱

对 Cola 说：“我要用 Muse 技能整理邮箱，请引导我连接邮箱，先只检查最近的收据。”

Cola 应使用它现有的邮箱连接功能，说明服务商、需要的权限和官方授权入口。你在服务商页面完成登录或授权，再回到 Cola 说“已完成”。不要把密码或应用专用密码直接贴到聊天里；如果连接流程需要这类凭证，应通过该连接器指定的本地安全输入方式填写。

首次验证只查一封你知道存在的测试邮件，核对日期、发件人和标题。连接成功后，再给出整理范围；“整理”不会自动授权删除所有邮件。

## 日历

对 Cola 说：“请连接我的日历，先创建一个专门测试用的日历或使用我指定的测试日历。”

首次写入前核对目标日历和时区。创建一条测试活动后，让 Cola 读回时间与活动 ID；重复同一任务不应产生第二条重复活动。确认无误再处理家庭日程。

## 购物、订票和商家网站

让 Cola 先列出候选和总价；需要登录时由你在官方页面完成。清楚说明是“只比较”“加入购物车”还是“按这些条件下单”。确认订单编号与服务状态后，才算预订成功。

后台浏览器用户沿用自己的浏览器偏好。需要前台登录时应交还已有任务页面，完成后再继续，不抢占鼠标或键盘。

## 电话、银行和智能家居

这些不随技能包附送：

- 电话：需要能实际拨号并双向对话的服务和号码。语音输入、配音、朗读都不等于打电话。
- 银行：需要受支持的金融连接器，且你的地区、机构和账户符合条件。可以先导出账单让 Cola 分析。
- 智能家居：需要自己的设备/平台实例和权限。先测试虚拟灯光等低影响对象，再考虑真实设备。

让 Cola 报告它实际探测到的状态。没有连接时应提供接入步骤或可先完成的部分，不能承诺已替你联系商家或操作账户。

## 停止使用

在服务商的“已授权应用/第三方连接”页面撤销权限，并告诉 Cola 移除不再需要的连接。卸载技能本身不会撤销账号授权，也不会清除外部服务里已经创建的订单、日程或消息。
