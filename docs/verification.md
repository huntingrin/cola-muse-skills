## 三个 Cola 实际调用场景

| 场景 | 独立验收 | 没有验证什么 |
| --- | --- | --- |
| 订阅收据审计 | 年付折算、重复 ID 去重、已取消/按量/状态未知独列；固定成本 420 元/年、35 元/月 | 真实 Gmail 检索、订阅取消、退款 |
| 学校日程整理 | 三个事件；旧时间被改期覆盖；UTC 换算；全天结束日排他；取消状态保留 | PDF OCR、在线日历写入、不同客户端导入行为 |
| 90 天项目计划 | 日期连续、每天不超过 30 分钟、2400 分钟工作量完整、300 分钟缓冲、依赖顺序正确 | 通用课程质量、长期坚持、提醒触发 |

这三个测试在隔离的 macOS Cola 运行时中调用真实模型。文件工具限定到合成资料目录，浏览器、渠道与自动任务关闭；模型请求仍连接 Cola 服务。订阅与计划通过明确技能名调用，学校日程让 Cola 在本套技能中选择合适的技能。每项本版本只有有限次数试验，不是稳定成功率研究。

计划场景中，代理临时编写的自检脚本有一次字符串比较错误，随后自行修正；任务最终产物通过独立验收。报告保留了这一次工具错误，不将“最终通过”表述为“全程无错”。

## 尚需真实接入验证

- 其余工作流已编写，但没有完成逐项模型行为和真实账号测试。
- 电话外呼：本次核对源码未找到内置实现，不等于所有外部技能都不支持；需要具体服务接入。
- 银行/券商实时连接：文件分析不等于账户同步；地区、接口和权限需现场核对。
- 购物、退款、保险、预订：网站可操作不代表商家受理、付款或退款成功。
- 生成媒体：取决于实际模型/服务、素材、规格与额度。
- 后台任务：Cola App 未运行时不保证执行；自动下单、付款、交易受到当前产品规则限制。
- 技能安装的跨平台行为由 GitHub Actions 矩阵验证；Cola 代理实测目前仅 macOS。
