# Cola Muse Skills

**把日常琐事交给 Cola：一句话安装，直接用中文交代任务。**

项目目标：**一键让 Cola 拥有 Muse 所有能力。**

这是一个持续建设的社区技能集。目前提供 **24 个任务技能 + 1 个总入口**，对照《1081 Muse Use Cases & Prompts》的全部条目建立了任务索引。**1081 条已收录不等于 1081 条已实测成功。** 电话、银行、商家等服务需要额外连接；现阶段的实际验证范围见 [测试结果](docs/verification.md)。

非 Cola 或 Muse 官方项目，与两者不存在官方合作或认证关系。

## 先看看它能帮你做什么

你可以像平时聊天一样说：

> 帮我看这些订阅收据，算清每个月固定花多少钱，列出可能省下的钱，先不要取消。

> 把这份学校通知整理成家庭日程，检查改期和接送冲突。

> 安排两个人五天的旅行，把机票、酒店、交通的总预算算清楚。

> 把我的项目拆成 90 天计划，每天最多 30 分钟，给我一份可打开的文件。

不需要记住技能名称。技能是给 Cola 看的办事流程；你只需要说明想要的结果。

## 三步开始

### 1. 打开 Cola

先安装并登录 [Cola](https://meetcola.com/)，确认它能正常回答问题。技能集本身免费，使用 Cola 模型或第三方服务可能消耗你的套餐、额度或产生服务费用。

### 2. 复制这段话，发给 Cola

```text
请帮我安装 https://github.com/huntingrin/cola-muse-skills 的技能集。
先读取仓库的 INSTALL.md，获取正式发布包，核对文件，然后按教程安装到我当前使用的 Cola。
安装后做自检，告诉我装好了多少个技能；不要连接任何账号、购买服务或改动其他技能。
```

Cola 会下载文件、执行安装并检查结果。正常情况下应显示 **25 个技能已安装**。下一条消息即可开始使用；如果没有识别，关闭并重新打开 Cola 后再试。

如果 Cola 提示需要文件访问权限，核对它请求的是本次下载文件夹或当前 Cola 的技能目录，再允许。**不需要把密码、支付信息或 API Key 发到聊天里。**

> 国内版、国际版或自定义目录都可安装。如果同时安装了多个版本，Cola 会先确定你要装到哪个版本，不会盲目改两个目录。

### 3. 做一个不用连接账号的小任务

直接复制：

```text
请用 Muse 技能帮我做一个三天计划，从 2026 年 10 月 1 日开始，每天最多 30 分钟。
我要先花 45 分钟列提纲，再花 15 分钟检查提纲。
请交付计划文件，核对每天有没有超时。不要创建提醒。
```

正常结果：第一天列提纲 30 分钟；第二天列提纲 15 分钟、检查 15 分钟；第三天可以留作缓冲。你应收到一个真实的计划文件，而不只是“建议你这样做”。

## 哪些可以直接用，哪些要先连接

| 你想做的事 | 需要准备什么 |
| --- | --- |
| 分析账单、整理文件、做计划 | 把相关文件交给 Cola；不用连接额外账号 |
| 做研究、比较商品、规划旅行 | 说明需求；需要可用的网页搜索或浏览能力 |
| 整理邮箱、更新日历 | 连接自己的邮箱或日历，见 [账号连接教程](docs/connect-accounts.md) |
| 做图片、视频、播客 | Cola 中对应制作能力可用，并有相应额度 |
| 订票、购物、退款、对外沟通 | 登录相应平台，说明允许操作的范围；最终结果受平台影响 |
| 代打电话、连接银行、控制智能家居 | 需要相应服务接入；本项目**不附送电话线路、银行接口或账号** |
| 每天执行、持续监控 | Cola 的运行时需要保持运行；关闭 App 后不保证执行 |

**特别说明：**当前 Cola 定时任务规则不支持自动下单、付款或交易。本套技能会遵守这个限制，不通过脚本绕过。

## 怎么更新、卸载

更新时发给 Cola：

```text
请按 huntingrin/cola-muse-skills 的 INSTALL.md 更新技能集，然后做自检。
保留我自己修改过的文件和其他技能；如果发现冲突，告诉我具体是哪一个。
```

卸载时发给 Cola：

```text
请按 huntingrin/cola-muse-skills 的卸载说明，只移除这个项目安装且未被我修改的技能。
不要删除我的任务产物，也不要修改其他技能或账号连接。
```

卸载技能不会撤销邮箱、日历等第三方授权，也不会自动删除已创建的定时任务。需要停用它们时请另外告诉 Cola，并在对应服务的账号设置里撤销授权。

## 遇到问题

| 现象 | 直接这样告诉 Cola |
| --- | --- |
| 安装后找不到技能 | “请按 INSTALL.md 做 doctor 自检，检查目录与技能是否启用。” |
| 不能读取邮件/日历 | “请只检查连接状态，告诉我需要在哪个官方页面授权。” |
| 提示文件被修改 | “请列出冲突文件和备份方法，先保留我的修改。” |
| GitHub 下载失败 | “请重试官方仓库发布包；仍失败就告诉我下载失败，不要改用不明镜像。” |
| 任务只做了一半 | “请列出已完成的证据、卡住的步骤和继续所需的信息。” |
| 不能代打电话 | “请检查是否真的有外呼服务；没有就先准备通话提纲，不要声称已经打过。” |

更多说明见 [安装说明](INSTALL.md) 和 [测试结果与限制](docs/verification.md)。

## 给开发者

无 npm 依赖。安装器与三个确定性工具使用 Node.js 18+；无需运行 `npm install`。

```sh
node scripts/validate.mjs
node --test tests/installer.test.mjs tests/workflows.test.mjs
node install.mjs install --data-dir /path/to/test-cola --dry-run
```

提交新能力时请同时提供输入、验收标准和可复核结果。[测试指南](eval/README.md) 说明如何区分离线测试、Cola 实际调用和真实业务成功。安装到个人账号前，可先在独立目录试验。
