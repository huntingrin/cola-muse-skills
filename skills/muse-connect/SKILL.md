# 服务连接与能力自检

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：已安装 Cola；连接必须由服务商官方授权入口完成。

## 工作流程

1. 先区分技能是否安装、工具是否存在、账号是否授权、服务是否支持所在地区、业务权限是否足够，分别记录。

2. 读取当前工具/技能清单，使用服务的无副作用状态查询；未做探测就标为 unknown。不要读取或输出凭证文件来证明登录。

3. 优先使用已连接应用和官方文档。新增接入先说明服务、权限、费用及必要步骤，再按授权安装；不因能安装 MCP 就声称具备所有能力。

4. 电话需要实际外呼、双向语音、号码与通话记录；银行实时同步需要对应金融接口；设备监控需要传感器/实例。缺少则给具体接入方案与可先完成的部分。

5. 配置后用只读或测试账号探测，再恢复用户原任务。连接完成与业务完成分别报告。

## 示例

> 检查 Muse 技能集能用哪些功能，列出还没连接的账号，不要读取密码。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
