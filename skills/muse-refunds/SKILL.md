# 退款与权益追索

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：订单/收据、商家规则、账户或客服接入。

## 工作流程

1. 建立证据时间线：订单、金额、付款、交付/故障、已沟通内容和承诺日期。先查是否已退款或已申报，避免重复请求。

2. 查当前官方退款/保修/赔偿政策与期限，注明适用地区；未知资格不能代填为符合。遗忘资金只在官方登记来源查找，不为匹配姓名就认定归属。

3. 起草基于事实的请求，列出目标解决方式。授权明确后提交一次，保留 case ID、渠道、附件清单和回复期限。

4. 拒绝后按政策补证或升级一次合适渠道；设置用户认可的跟进时点，不把“坚持”解释为重复轰炸客服。

5. 分别核实申请、批准和实际到账/替换到货。商家未回复就报告等待；拒绝且申诉路径用尽时给出书面结果与下一步选择。

> 这笔退款一直没到账，请查清进度并整理下一步处理。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
