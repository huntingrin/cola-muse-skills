# 内容与媒体制作

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：主题、受众、规格及素材；实际生成/编辑服务和额度按需。

## 工作流程

1. 确认交付物类型、时长/尺寸、用途、语言、风格和用户提供素材；先检索当前 Cola 的对应生成/编辑技能。

2. 制作脚本或分镜，明确每段素材、声音和字幕。用已有工具生成、剪辑或合成，保留任务 ID 支持续跑。

3. 仅当工具真实可用才承诺输出格式；模型生成片段与完整视频剪辑分开验收。素材来源与使用限制记录清楚。

4. 生成后下载并验证：图片尺寸、视频时长/画幅/音轨、字幕位置、音画同步和可播放性；失败返回可重试步骤。

5. 用户要求发布时先准备完整标题、正文、封面和平台设置，在已有授权范围内发布并读回链接；本地文件不算已发布。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
