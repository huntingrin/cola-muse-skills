# 社交媒体分析与运营

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：用户自己的账号授权或数据导出；平台接口或允许的页面操作。

## 工作流程

1. 确认平台、账号、时间窗和目标，区分曝光、播放、触达、互动、关注净增等口径。

2. 完整获取分页与时间数据，标注缺失；净增与曝光相关不证明内容导致涨粉，不夸大结论。

3. 比较内容形式、主题与发布时间，给出具体下一轮试验和衡量方式；涉及同业只处理公开数据。

4. 关注/取消关注、删除帖子、发布和私信按用户明确范围执行。不能把 API 不支持当成绕过平台限制的理由。

5. 发布后核对 permalink、文案和媒体；效果复盘保留原始数据快照。

## 示例

> 分析我最近 30 天的内容数据，找出表现最好的主题并建议下周实验。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
