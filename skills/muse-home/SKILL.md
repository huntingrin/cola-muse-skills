# 居家维护与智能家居

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：房屋/设备资料、预算、地点；服务商或 Home Assistant 接入按需。

## 工作流程

1. 区分紧急危险与一般维修；燃气、电气、结构等危险先让用户联系合适专业人员，不远程猜测安全。

2. 整理照片、型号、症状和用户观察，形成对不同服务商一致的询价范围；对比人工、材料、质保和时间。

3. 租房比较总成本、租期、押金、停车与限制；基于用户授权沟通和预约，不代签未确认合同。

4. 智能家居先确认实体和当前状态，在虚拟实体或低影响场景试验；门锁/报警等动作需要明确范围和可恢复路径。

5. 维修、订单、设备动作以回执或读回状态核验；监控必须已有数据接入，不能声称凭空发现空调故障。

## 示例

> 帮我对比三个热水器安装报价，列出漏项、保修和最终总价。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
