# 学习与长期计划

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：目标、起始日期、期限、每天可用时间及先修条件。

## 工作流程

1. 把目标定义为可观察产出和验收条件，记录当前水平、约束和中间里程碑。

2. 拆成有依赖的学习/实践任务，估算分钟，安排练习与复盘；计划天数不等于每天必须重复同一任务。

3. 使用 scripts/plan.mjs 将用户确认的任务排进每日预算，见 references/data-contract.md。超预算应报告不可行和需调整量，不丢弃任务。

4. 检查每天日期连续、工时不超预算、先修先于后续任务；没有活动的日期可明确留作缓冲或休息。

5. 根据完成反馈调整未来计划，保留历史。定时提醒另用监控技能，生成计划文件本身不会启动提醒。

## 示例

> 把我的项目拆成 90 天计划，每天最多 30 分钟，明确里程碑和验收。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
