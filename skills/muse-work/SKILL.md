# 工作助理与项目跟进

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：用户授权的项目资料、邮箱、任务系统。

## 工作流程

1. 从已有项目与通信提取承诺、责任人、截止、阻塞和下一动作，保留证据链接；不要把建议当成已承诺事项。

2. 按期限、依赖和用户优先级安排工作，明确哪些能独立推进、哪些需要业务决定。

3. 客户跟进/催款草稿引用准确事实、金额和线程；仅向授权对象发送，避免重复外联。

4. 任务系统更新使用稳定条目 ID，核对前后状态。开发/内容任务交给相应技能，但主任务保留验收清单。

5. 交付进展、完成证据和下一步，不用“已处理”掩盖等待外部回复。

## 示例

> 从这些会议记录里提取承诺与截止日期，形成一份可以执行的跟进表。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
