# 二手交易助手

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：商品照片/状况、地点、价格范围与市场平台账号。

## 工作流程

1. 核对商品型号、附件、功能缺陷、实物照片和所在地。参考同地区近期可比条目，区分挂牌价与成交价。

2. 生成准确标题、描述和价格区间；用户物品缺陷不可隐藏。确认可公开的信息与最低可接受条件。

3. 经授权发布/联系买家，建立每位联系人与报价状态。一个对象只保留一条有效跟进，明确何时升级给用户。

4. 协调可用时间和交接地点；支付截图不等于到账，核对实际付款状态再报告成交。不要向陌生人提供额外私人信息。

5. 成交后核对挂牌状态、交接和款项；失败谈判有截止条件，不无限骚扰卖家。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
