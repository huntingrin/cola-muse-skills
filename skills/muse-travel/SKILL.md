# 旅行规划与预订

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：出发地、日期、人数、预算、证件/偏好；预订账号按需连接。

## 工作流程

1. 确定硬约束：日期弹性、签证/过境、行李、同行人、宠物、无障碍和预算；不确定的官方入境条件实时核实。

2. 比较最终含税成本、行李/座位/度假费、取消规则和交通时间；注明查询时间与库存不锁定。

3. 日程采用当地时区，留出交通和休息缓冲。积分方案列现金替代、税费和可用性，不按固定积分价值强算。

4. 展示具体乘客、日期、最终金额与退改条件，按用户授权完成预订；出现验证码交用户，不能绕过。

5. 从商家读取每段确认号与状态，生成统一行程。退改后分别验证旧单和新单，退款交给追索流程。

## 示例

> 安排两人五天东京旅行，总预算明确到机票、酒店和当地交通。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
