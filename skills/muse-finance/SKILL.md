# 财务记录与分析

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：用户提供的财务文件，或已授权的只读金融集成。

## 工作流程

1. 确定账户、时期、币种和数据更新时间。接入缺失时使用用户提供的导出文件；不声称静态文件是实时银行连接。

2. 区分收入、支出、内部转账、退款、资产估值和负债；按交易 ID 去重，保留原始来源。汇率与估值给出日期。

3. 税表/报销按清单汇集，标记缺失和潜在可抵扣项目；不在没有证据时认定税务资格。提交前展示具体内容。

4. 分析或看板采用可复算口径。投资观点区分历史数据与推测，不能保证收益；模拟交易与真实订单严格分开。

5. 若任务涉及真实资金操作，核验连接与明确交易授权并遵守 Cola 规则；缺失时交付分析和待办，不绕过限制。
