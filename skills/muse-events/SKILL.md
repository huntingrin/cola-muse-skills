# 聚会与活动筹备

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：日期、人数、预算、偏好与可用日历；预订账号按需。

## 工作流程

1. 确认固定日期、人数、预算上限、地点和关键偏好；把场地、餐饮、交通、礼物、宾客和负责人列成依赖清单。

2. 实时核对可用性和总成本，记录订金、取消条款和最后确认日期；不要把询价当成锁定席位。

3. 使用既有通讯录中授权联系人，先形成可审阅邀请和供应商请求，再按发送授权联系。

4. 预订逐项读回确认；宾客过敏与无障碍需求影响场地/餐饮选择，变更后同步所有相关事项。

5. 交付当天执行表、联系人与备用方案，隐去不必要的个人信息。

## 示例

> 为孩子安排生日聚会，预算 2000 元，先给场地、餐饮和时间安排。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
