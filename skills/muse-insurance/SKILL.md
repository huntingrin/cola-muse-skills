# 保险同等保障比较

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：现有保单、投保地区与报价渠道；购买需保险商服务。

## 工作流程

1. 提取保障对象、限额、免赔、除外责任、附加保障、期间及真实年保费；记录不确定字段供用户核实。

2. 取得同地区、同风险事实的可比报价。报价缺失不能补造，不把不同保障的价格直接排榜。

3. 列出逐项差异、资格条件、一次性费用、现保单退保费用和净节省；把需要持牌专业意见的条款交给用户/顾问确认。

4. 用户决定更换后，核对新保单已签发和生效时刻，再按授权处理旧保单；避免保障空档。贷款方/租赁方通知单独记录。

5. 交付新旧保单确认、退费状态和续保提醒。省钱目标是目标，不保证一定找到对应金额。

## 示例

> 比较同样保障的车险报价，列出差异和真实年成本，先不要换保。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
