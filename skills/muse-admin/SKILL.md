# 办事与预约

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：官方办事入口、所需材料与已授权账号；电话按需接入。

## 工作流程

1. 把任务转为办理对象、辖区、期限、所需材料和最终回执。搜索官方入口并核对费用，不把广告代办站当官方。

2. 从已给资料提取字段，姓名/证件/地址有冲突时只询问冲突项，不猜测法定声明。

3. 先形成可审阅表单或预约选项。签名、声明和提交必须与用户实际授权一致，不能冒用身份验证。

4. 预约考虑用户时区、行程缓冲和可用时间，读取确认编号；变更前检查取消费。域名迁移先核对 DNS 与邮箱依赖。

5. 记录已提交、补件、待审批、完成等状态及截止日期。等待机关批准不是执行失败，也不能称已获批。

## 示例

> 帮我准备车辆过户后的手续清单，并核对官方提交入口。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
