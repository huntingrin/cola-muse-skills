# 家庭日历与孩子事务

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：家庭时区、成员与可用日历；学校资料或授权门户。

## 工作流程

1. 从原始邮件/PDF逐项提取孩子、活动、地点、起止、报名截止和改期；一个活动的更新覆盖旧安排，取消明确处理。

2. 标明时间来源与时区，重复规则和假期例外；不把“报名截止”当成活动开始。家庭接送加交通缓冲。

3. 先核对冲突和家长责任分工；向指定家庭日历写入，使用源事件 ID 或稳定 UID 保证重跑不重复。

4. 离线日程可用 scripts/calendar.mjs 导出 ICS，见 references/data-contract.md；ICS 文件不代表已写入在线日历。

5. 报名、同意书与对外联系按授权执行；读取确认回执。未成年人信息只用在指定目的和接收方。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
