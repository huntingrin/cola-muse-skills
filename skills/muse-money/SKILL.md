# 订阅与支出审计

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：邮箱/账单文件；取消时需要对应服务账号。

## 工作流程

1. 确定审计时间窗、币种和数据来源。收集账单与邮件收据，记录每笔日期、商户、金额、周期及原始证据；跨来源匹配交易 ID，防止重复计数。

2. 区分月付、年付、按量、一次性、退款和已取消。年费可以除以 12 表示折算月成本，但不能伪装成每月现金流。按量费用独列；不同币种不直接相加。

3. 生成统一 JSON 后可用 scripts/audit-subscriptions.mjs 计算确定性部分，输入格式见 references/data-contract.md。无法识别是否仍续费时标记 unknown，不猜测。

4. 给出确认中的持续成本、已取消项目、待核实和节省候选。候选节省不能当成已经省下的钱；使用频率不能仅凭收据推定。

5. 用户要求取消且对象明确时执行对应服务流程；读取取消生效时间与确认编号，检查是否仍享有已付费时段。退款交给退款流程。
