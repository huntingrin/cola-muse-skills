# 研究与个性化简报

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：主题、受众和时间范围；公开检索或用户授权信息源。

## 工作流程

1. 确定研究问题、决策用途、时效窗口和时区。个性化只使用用户授权的兴趣资料，不擅自读取全部账号。

2. 检索多种来源，核心事实回到原始公告、文档、论文或官方数据；打开具体页面，核对发表与事件时间。

3. 消除转载重复，区分事实、作者主张和你的推断；冲突资料并列说明，不造链接或时间。

4. 形成带来源的简报、比较表或报告，解释与用户问题的关系；未知项列出后续核实方式。

5. 循环简报交给监控技能，每次执行动态计算日期，复用已发条目 ID 防止旧闻重复。

## 示例

> 给我一份最近七天的行业简报，每条附原始来源，并说明与我的项目有什么关系。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
