# 应用与自动化构建

先读取 [执行与验收约定](references/contract.md)，再按本任务流程执行。

所需条件：功能目标、输入输出样例、可写项目目录；部署账号按需。

## 工作流程

1. 把需求变为用户可完成的操作与验收条件；选最小可维护实现，先确认已有项目约束，保留用户改动。

2. 以实际数据结构制作界面和逻辑，敏感账号通过已授权接口或用户输入接入，不把凭证嵌进页面。

3. 运行构建与关键行为测试；前端在用户允许的后台浏览器内验证主流程。不能只凭生成代码宣称能用。

4. 有静态/模拟数据时界面明确标注；涉及实时账户需要连接状态、时间戳和失败处理。

5. 部署依据用户授权，验证线上链接和持久化；给出启动、使用、更新和回滚说明。

## 示例

> 用这些合成数据做一个本地支出看板，验证筛选和总金额正确。

## 完成时

交付实际结果、可核对的证据和未完成事项。外部连接缺失时说明阻塞点，不能把步骤说明当作已经执行。
